**Что это:** OpenAI-совместимый AI-глубинный шлюз с роутингом между многими LLM-провайдерами, встроенным MCP сервером (25 инструментов), десктопным приложением (Electron), CLI.

| Возможность | Реализация | Статус |
|-------------|------------|-----------|
| Мультипровайдерный роутинг | Да — 75+ провайдеров через один endpoint | ✅ |
| Авто-фолбэк между провайдерами | Да | ✅ |
| Мультиаккаунт на одного провайдера | Да | ✅ |
| Десктоп приложение | Да (Electron) | ✅ |
| Web UI | Да | ✅ |
| MCP сервер | Да (25 инструментов) | ✅ |

### 2.2 Claude Code (Anthropic)

**Возможности:**
- Полноценный терминал в интерфейсе
- Git-операции (коммит, push, ветки)
- Интерактивный TUI
- MCP расширения
- Мультиагентность
- Саб-агенты

**Отличия от Odyssey:**
- Claude Code — локальный клиент, работающий с локальными файлами
- Odyssey — серверная платформа с изолированными sandbox-контейнерами
- Claude Code не имеет встроенного изолированного sandbox для кода

### 2.3 Claude Codex (OpenAI)

**Возможности:**
- Терминальный AI-агент
- OpenAI API под капотом
- Редактирование файлов, команды
- Встроенные инструменты

## 4. Сильные стороны Odyssey CLI

1. **Изолированный sandbox** — Docker + gVisor обеспечивает реальную изоляцию кода, что отсутствует у Claude Code, Codex и OmniRoute
2. **Серверная политика одобрения** — модель не может расширить права без владельца
3. **Чекпоинты и откат** — уникальная функция для отката изменений задачи
4. **Детальный учёт стоимости** — каждый вызов модели учтён
5. **Тарифная система** — бесплатный + платный уровень + кредиты
6. **Память проекта и «Обо мне»** с подтверждением фактов
7. **Полный REST API** — любая интеграция возможна
8. **Кроссплатформенный CLI** — Python, работает везде

## 11. Заключение

Odyssey CLI имеет прочную основу с полным покрытием API бэкенда. Основные направления развития:

1. **Интерактивность** — полноценный терминал и TUI
2. **Удобство использования** — лучший вывод, автодополнение, история
3. **Интеграция с Git** — полноценная работа с репозиториями
4. **Автоматизация** — параллельные задачи, саб-агенты

Проект имеет хороший потенциал и уже 덮ycjiвает многие ключевые функции, которых нет у конкурентов (изолированный sandbox, серверная политика одобрения, чекпоинты, детальный учёт стоимости).
