# Сложность реализации функций — только CLI-часть (без бэкенда)

Источник: `/root/odyssey-cli` (кастомный CLI на Python, httpx + argparse + Textual).

Оценка сложности для разработки только клиентской стороны (CLI), при условии что бэкенд API уже существует или предоставляет нужные эндпоинты. Если функция требует новых бэкенд-эндпоинтов — помечено как **зависит от бэкенда** (CLI-обёртка сама по себе простая, но без бэкенда не работает).

Шкала: **Low** (до 1 дня), **Medium** (1–3 дня), **High** (3–7 дней), **Very High** (1–2 недели).

## 2. Рекомендуемые новые функции (CLI-only, без бэкенда)

| # | Функция | Сложность | Обоснование |
|---|---|---|---|
| 1 | **Глобальный флаг `--json` для всех команд** | Low | Сейчас есть только у некоторых команд. Добавить единый формат вывода JSON для всех mutating-команд. |
| 2 | **Глобальный флаг `--verbose` (стек-трейс при ошибках)** | Low | Уже частично реализован в `main.py`, но не все команды используют. Добавить единую обработку. |
| 3 | **Цветной вывод (цветная подсветка статусов)** | Low | Использовать ANSI-коды или `rich` для цветного вывода статусов (running/completed/failed) в командных строках. |
| 4 | **Поддержка stdin для команд `files edit`, `run message`** | Low | Уже частично реализовано (`content == "-"`). Расширить на все подходящие команды. |
| 5 | **Команда `config list` (весь конфиг в читаемом виде)** | Low | Уже есть `config show`. Дополнить форматом таблицы. |
| 6 | **Автодополнение (shell completion) для bash/zsh/fish** | Medium | Нужно сгенерировать скрипты дополнения для всех подкоманд и флагов. |
| 7 | **Экспорт файла из workspace (`files download <path>`)** | Medium | Требует скачивание файла по API и сохранение локально. Потоковая загрузка large-файлов. |
| 8 | **Импорт локального файла в workspace (`files upload <local> <remote>`)** | Medium | Чтение локального файла, отправка через API. Ограничение размера тела запроса. |
| 9 | **Показ дерева файлов в компактном виде (`files tree`)** | Medium | Рекурсивный обход каталогов через повторные `files list`, отрисовка дерева с отступами. |
| 10 | **История команд CLI (хранение последних команд в конфиге)** | Medium | Сохранение последних N команд в `~/.odyssey-cli/history`, возможность повтора. |
| 11 | **Параллельное выполнение нескольких команд** | Medium | Асинхронное выполнение независимых команд (например, `files list` для нескольких workspace). |
| 12 | **Интерактивный режим (REPL) без подком commands** | High | Интерактивный цикл ввода команд с подсказками, автодополнением, историей. Требует `prompt_toolkit` или `rich`. |
| 13 | **Визуализация графа зависимостей задач (runs graph)** | High | Построение графа связанных ran, сессий, workspace с зависимостями. Требует накопления состояния в CLI. |
| 14 | **Экспорт/импорт конфигурации CLI (`config export\|import`)** | Medium | Экспорт токена и URL в JSON/ENV-файл, импорт из другого окружения. |
| 15 | **Команда `doctor` (проверка окружения и подключения)** | Low | Проверка `ODYSSEY_API_URL`, токена, доступности `/health` и `/ready`. |
