## 2. Архитектура и развёртывание

### Odyssey AI
- **Серверная архитектура:** FastAPI + SQLAlchemy + Alembic + PostgreSQL + Redis + Docker + runner-manager (gVisor sandbox).
- **Развёртывание:** Собственный сервер через `docker compose`. Требует запуска backend (web), worker, runner-manager, Redis, PostgreSQL.
- **Изоляция:** Каждый workspace — отдельный Docker-контейнер с gVisor (runc), read-only корневая файловая система, нетворк через egress-прокси (только 80/443, нет приватных адресов).
- **Безопасность:** Docker-сокет только у runner-manager. API и worker не имеют доступа к Docker. Workspace файловые операции отвергают symlink-траверсал. Approval policy — серверная, модель не может расширить права.
- **Чекпоинты/откат:** Дисковый чекпоинт workspace перед первой aprobации. Возможность отката отдельного файла или всего ran.

### OpenCode
- **Серверная архитектура:** Открытый исходный код (MIT), TypeScript/Node.js. Может запускаться локально без центрального сервера.
- **Развёртывание:** Локальная установка через curl/npm/brew. Не требует центрального сервера для базовой работы.
- **Изоляция:** Зависит от выбранной модели и среды выполнения (локальный терминал).
- **Безопасность:** Запрос разрешения перед правкой файлов и запуском команд (режим plan).

### Codex
- **Серверная архитектура:** Открытый исходный код (Apache-2.0), Rust/Node.js. Запускается локально.
- **Развёртывание:** Локальная установка. Требует ChatGPT аккаунт или OpenAI API ключ.
- **Изоляция:** Локальное выполнение в терминале пользователя.
- **Безопасность:** Запрос разрешения перед действиями.

### Claude Code
- **Серверная архитектура:** Закрытый код. Запускается локально в терминале пользователя, общается напрямую с API Anthropic.
- **Развёртывание:** Локальная установка через curl. Требует Claude аккаунт.
- **Изоляция:** Локальное выполнение. Разработан с учётом безопасности, не требует центрального бэкенда.
- **Безопасность:** Запрос разрешения перед изменениями файлов и командами.

## 3. Модели и стоимость

### Odyssey AI
- **Модели:** Управляются через OpenRouter. Планая модель по умолчанию — Claude Haiku 5.5. Бесплатные — Nemotron 3.5 Super, Nemotron Ultra, Laguna (через OpenRouter :free).
- **Тарифы:** Бесплатный (5 задач/день, лимиты $0.10/задача, $0.20/5ч, $0.30/неделя, $0.60/месяц) + «Стандарт» 990 ₽/мес (лимит $0.50/задача, $1.00/5ч, $2.50/неделя, $5.50/месяц) + кредиты (200 ₽ за $1).
- **Учёт затрат:** Детальный учёт каждого вызова модели в таблице `ai_usage` (провайдер, модель, стоимость, токены, латентка, generation ID). Окна расходов: 5 часов, неделя, месяц.
- **Лимиты на запрос:** CHAT_MAX_REQUEST_COST_USD (резервация перед вызовом), AGENT_MAX_RUN_COST_USD (лимит на задачу).

### OpenCode
- **Модели:** 75+ провайдеров через Models.dev (Claude, GPT, Gemini, локальные модели). Пользователь выбирает модель вручную.
- **Тарифы:** CLI бесплатно. Стоимость зависит от выбранной модели. Есть бесплатные модели.
- **Учёт затрат:** Зависит от провайдера модели.

### Codex
- **Модели:** Модели OpenAI (GPT family).
- **Тарифы:** CLI бесплатно. Стоимость через тариф ChatGPT (Plus/Pro/Business/Edu/Enterprise) или API ключ OpenAI.
- **Учёт затрат:** Зависит от тарифа OpenAI.

### Claude Code
- **Модели:** Claude Opus, Sonnet, Haiku, Mythos (Anthropic).
- **Тарифы:** Claude Pro / Max / Ultra; Team $20/месяц на место (годовая оплата); Enterprise — индивидуально.
- **Учёт затрат:** Стандартные тарифы API Claude (за токены). Fast mode для Opus 5.5 ($8/$40 за млн токенов).

- Чтение и запись файлов

- **Изолированные Docker+gVisor sandbox** для каждого workspace с собственной дисковой卷 и сетью через egress-прокси

- **Тарифная система:** бесплатный + платный (990 ₽/мес) + кредиты
- **Память проекта и «Обо мне»** с подтверждением фактов через `remember` tool
- **Фоновые процессы** в отдельном контейнере (до 2 на проект, до 30 мин)
- **Сборка APK и экспорт Godot** из задач (в roadmap/сделано, не выкачено)

- **Аудит логов** (метаданные без содержимого промптов)

### Уникальные возможности OpenCode
- **Поддержка 75+ LLM-провайдеров** через Models.dev (Claude, GPT, Gemini, локальные модели)
- **Встроенные агенты:** `build` (полный доступ), `plan` (только чтение), `general` (подзадачи) — переключаются клавишей `Tab`
- **Полностью открытый исходный код** (MIT) — можно форкать и модифицировать
- **Десктопное приложение** (бета) для macOS/Windows/Linux

### Уникальные возможности Codex
- **Интеграция с экосистемой OpenAI** (ChatGPT Plus/Pro, API ключ)
- **Codex Web** — облачный агент (chatgpt.com/codex)
- **Интеграция с Cursor, Windsurf** IDE
- **Открытый исходный код** (Apache-2.0)

### Уникальные возможности Claude Code
- **Интеграция со Slack**
- **Мобильные приложения** (iOS, Android)
- **Auto mode** по умолчанию на платных тарифах (август 2026)

## 6. Преимущества Odyssey AI перед конкурентами

1. **Изолированные sandbox-Workspace** — каждая задача выполняется в отдельном Docker+gVisor контейнере с собственной диском и сетью, что исключает воздействие на хост и утечки между задачами.
2. **Серверная политика одобрения** — модель не может обойти права доступа, все решения принимаются на сервере (approval_policy.py).
3. **Чекпоинты и откат** — возможность вернуть состояние workspace до начала задачи, включая отдельные файлы.
4. **Детальный учёт стоимости** — каждый вызов модели учитывается с привязкой к пользователю и окнам расходов (5ч/неделя/месяц).
5. **Тарифная система** — бесплатный тариф + платный (990 ₽/мес) + кредиты, что подходит для монетизации.
6. **Память проекта и «Обо мне»** с подтверждением фактов через `remember` tool.
7. **Собственный REST API** — возможность интеграции через стандартные HTTP-запросы, в отличие от閉源 CLI конкурентов.
8. **Соблюдение 152-ФЗ** — хранение данных на сервере в РФ (план переезда в Москву).

## 7. Недостатки Odyssey AI по сравнению с конкурентами

1. **Нет нативного TUI на уровне Claude Code/OpenCode** — есть базовый TUI на Textual, но меньше функций, чем у Claude Code.
2. **Нет встроенных мобильных приложений** (в отличие от Claude Code).
3. **Нет интеграции со Slack** (в планировании через Telegram).
4. **Нет нативной интеграции с VS Code/JetBrains** (в отличие от Claude Code, Codex).
5. **Требует развёртывания собственного сервера** (Docker Compose), в то время как конкуренты работают «из коробки» после установки CLI.
6. **Нет GitHub App интеграции** (в roadmap, не реализовано).
7. **Меньше встроенных моделей по умолчанию** (зависит от OpenRouter ключа).
