## Подробный разбор по категориям

### 1. Лицензирование и открытость

- **OpenCode** — полностью открытый исходный код под лицензией MIT. Репозиторий на GitHub (anomalyco/opencode) с 223k звёздами, 30k форками, 21.8k коммитами. Любой может модифицировать, форкать и внедрять в свои проекты.
- **Codex** — открытый исходный код под лицензией Apache-2.0. Репозиторий openai/codex с 132k звёздами, 20.9k форками, 12.9k коммитами.
- **Claude Code** — проприетарный продукт Anthropic. Исходный код закрыт. Доступен только через официальные каналы распространения.

### 2. Модели и провайдеры

- **OpenCode** — 가장 гибкий: поддерживает 75+ LLM-провайдеров через Models.dev, включая Claude, GPT, Gemini и локальные модели. Пользователь сам выбирает модель. Есть встроенные бесплатные модели.
- **Codex** — привязан к экосистеме OpenAI (модели GPT). Требует ChatGPT подписку или API ключ OpenAI.
- **Claude Code** — привязан к моделям Anthropic (Opus, Sonnet, Haiku, Mythos). Требует Claude подписку (Pro/Max/Ultra) или Console аккаунт с API ключом.

### 3. Ценообразование

- **OpenCode** — сам CLI бесплатен. Стоимость зависит только от выбранной модели. Бесплатные модели включены.
- **Codex** — CLI бесплатен (открытый код), но использование моделей оплачивается через тарифы ChatGPT или API OpenAI.
- **Claude Code** — CLI бесплатен для скачивания, но потребляет API токены Claude по стандартным тарифам. Team план: $20/месяц на место (при годовой оплате). Enterprise — индивидуально.

### 4. Интерфейсы и платформы

Все три инструмента доступны как терминальные CLI, так и через десктопные приложения и веб-интерфейсы. Claude Code дополнительно поддерживает мобильные приложения (iOS, Android) и интеграцию со Slack. OpenCode имеет десктопное приложение (бета) и IDE расширение для VS Code.

### 5. Автономия и права доступа

Все три агента работают в режиме, где они запрашивают разрешение перед модификацией файлов и запуском команд. Claude Code имеет "Auto mode" по умолчанию на платных тарифах (август 2026), что позволяет ему работать дольше без прерываний, но всё ещё спрашивает перед рискованными командами. OpenCode имеет отдельный режим "plan" (только чтение, запрос разрешения на правки).

### 6. Интеграция с экосистемой

- **OpenCode** — гибкая интеграция с любыми моделями через Models.dev, GitHub Copilot, ChatGPT Plus/Pro.
- **Codex** — интеграция с ChatGPT, IDE (VS Code, Cursor, Windsurf), Codex Web.
- **Claude Code** — интеграция с GitHub/GitLab, Slack, VS Code, JetBrains, Claude desktop, Claude Cowork, Claude Design.

## Итоговая таблица рекомендаций

| Ситуация | Лучший выбор | Обоснование |
|---|---|---|
| Нужен полностью открытый и настраиваемый инструмент | **OpenCode** | MIT лицензия, любой провайдер моделей, бесплатно |
| Уже есть подписка ChatGPT Plus/Pro | **Codex** | Нативная интеграция с экосистемой OpenAI |
| Уже есть подписка Claude / нужно Team/Enterprise | **Claude Code** | Лучшая интеграция с Claude моделями, корпоративные фичи |
| Нужен self-hosted / приватная инсталляция | **OpenCode** или **Codex** | Оба имеют открытый код |
| Нужен доступ из Slack / мобильных устройств | **Claude Code** | Поддержка Slack, iOS, Android |
| Нужно работать с несколькими моделями одновременно | **OpenCode** | Поддержка 75+ провайдеров через Models.dev |
| Бюджет ограничен, нет платных подписок | **OpenCode** | Бесплатные модели встроены, нет обязательной подписки |

## Сводка

Все три инструмента представляют собой терминальные AI-кодинг агенты с обширным набором схожих возможностей: автоматизация написания кода, работа с Git, интеграция с IDE, поддержка мультисессий. Основные различия лежат в плоскости лицензирования (открытый vs закрытый код), выбора модели (гибкий vs привязанный к одному провайдеру) и ценообразования (бесплатно vs подписка на модель).

OpenCode выделяется гибкостью выбора моделей и полной открытостью. Codex — интеграцией с экосистемой OpenAI. Claude Code — зрелостью корпоративных функций (Team/Enterprise, Slack, мобильные приложения,self-hosted окружения).
